
# Relief Stock Demand Analyzer

CS-102 Programming Fundamentals, Lab 08 (UET Peshawar)

A modular C++ program that stores ten item codes and demand values in
parallel one-dimensional arrays. It validates input, calculates total and
average demand, finds the highest and lowest demand, counts items above
average, searches by item code, collects urgent items, and prints a reverse
review list.

## How to compile and run
g++ Lab08.cpp -o lab08
./lab08

## Notes
- Uses only one-dimensional arrays (no 2D arrays, dynamic memory, or files).
- Arrays are passed to functions together with their size.
